# Creator Scout 独立首页交互原型

> **2026-09-24 已验收：账户浮窗尺寸与切换交互**。用户已确认264px紧凑尺寸及最终个人／团队切换手感。底边距账户入口8px，成功切换后保留同一浮窗，高度按当前内容约150ms平滑收放，上边缘及切换按钮随高度移动，不固定顶部或预留最大高度空隙。小窗口限高滚动，减少动态效果模式跳过伸缩。切换中／失败不重绘背景，成功同步目标；主动关闭后不重开、不抢焦点。
>
> 当前统一依据：[产品规格第10节](../需求说明/登录首页_统一需求规格.md)和[账户浮窗规范](../design-spec/pages/account-popover.md)；实现、既有测试与用户最终确认见[BOTTOM_ANCHOR_REPORT.md](BOTTOM_ANCHOR_REPORT.md)。无明确新要求，不回退旧尺寸、空间选择列表、成功自动关闭或固定顶部方案。本次仅同步文档，不改代码，不把局部通过扩大为全首页、账户内部功能或真实服务验收。

> **2026-09-24 浮窗紧凑版**：最新用户确认覆盖旧浮窗324/326/280px及44px菜单规范，现为264px含边框、38px菜单、36px头像、18px图标。亮度与业务交互保留。详见 `POPOVER_COMPACT_REPORT.md`。最新首页Figma视觉同步已由用户暂缓，本次不做该项、不宣称已对齐最新Figma。


一个可独立运行的 Creator Scout 首页原型：深色首页 + 品牌标识 + 左侧 AI Agent / 项目 / 最近三分区 + Instagram 默认空白会话 + 账户浮窗（四态规则）+ 团队/个人空间切换（按空间隔离项目、最近会话与未发送输入）。

> **性质声明：这是前端演示原型。**
> 本原型使用本地演示数据（fixtures），**未接入**真实账号、AI、采集、计费、邮箱或通知服务；
> 未合并、修改或嵌入 V9 demo（`智能挖掘_任务详情_v9_demo.html`）。
> 除「空间切换 / 会话恢复 / 草稿保存 / 退出确认」为真实的本地前端状态外，
> 其他未接入功能只给「暂未开放」提示，**不伪造任何成功结果**。

## 运行方式

无需安装依赖、无后端。两种方式任选：

1. **直接双击打开**：`creator-scout-home/index.html`（file:// 即可运行，原型未使用 ES Module）。
2. **本地服务（可选）**：

   ```bash
   cd "creator-scout-home"
   python -m http.server 8734
   ```

   浏览器访问 <http://localhost:8734/index.html>

自动测试页：`creator-scout-home/tests/tests.html`（同样可直接打开），运行四态浮窗矩阵、
空间隔离、草稿恢复、竞态守卫、失败重试等本地逻辑断言，并附带本地264px四态对照板（含管理员）。

本机已装 Python + Playwright 时，当前回归入口如下（产出独立截图与测试结果）：

```bash
cd "creator-scout-home"
python tests/verify.py        # 端到端：页面内测试 + 主流程操作 + 截图 + 1280×800 适配
python tests/verify-compact-popover.py  # 264px尺度、四态、颜色/对齐、提示避让及上一轮交互回归
python tests/verify-switch-continuity.py  # 连续性：同节点、底边贴合、背景更新次数、关闭/焦点及失败重试
python tests/verify-bottom-anchor.py  # 最新验收：逐帧8px间距、150ms高度过渡、中断/小窗/减少动态效果及完整回归
# layout-audit.py / color-audit.py 保留历史用途，不能作为最新Figma或本轮紧凑版验收入口。
```

## 已实现（前端演示可用）

- **00–05 完整流程（2026-09-24 新增，本地模拟）**：输入与发送需求 → 添加链接/选择附件 → 模拟读取与解析（01）→ 需求理解结果与画像引导（02）→ 用户主动打开并编辑项目画像（03 自适应分屏，对话与画像共用草稿）→ 对话修改 → 命名弹窗（04）→ 项目创建成功（05：项目入区、会话绑定、名称同步）。会话/画像/项目持久化，刷新与最近返回恢复，不重复追加消息。输入框聚焦只显示外层一圈 Mint 边框。
- **画像纠偏（2026-09-25）**：分屏为侧栏、430px 对话栏、占满余量的画像栏；画像字段采用 V9 的原位完成／取消、新增草稿卡与自动命名语义。字段阅读态完整换行。详见 [V9_PORTRAIT_CORRECTION_20260925.md](V9_PORTRAIT_CORRECTION_20260925.md)。
- 首页与品牌：**已同步最新 Figma 306:74（2026-09-24 复核）**——空白会话为官方 Instagram 渐变字形标识（40×40，Figma 导出位图，像素级一致）+「你想找什么样的 Instagram 达人？」28px 主标题 + 单行副标题 + 输入框（描边 #444852，聚焦转 Mint），原「三栏输入提示」与底部说明已按最新稿移除；品牌使用已有 Figma 导出的**转轮廓 SVG**（深底横版 524:329，无字体依赖）。
- 账户浮窗：264px宽（含边框）、菜单高38、外框圆角8、无投影；头像36、菜单图标18、昵称/菜单14px。四态规则不变。
  点击外部 / Esc 关闭；仅切换按钮悬停或键盘聚焦显示提示。提示独立在浮窗外定位，右侧不足时避让至上/下方；切换中保留反馈。
- 空间切换（**2026-09-24 用户已确认的交互**）：点击浮窗切换按钮**直接切换到另一空间**——账号永远保留一个个人空间、最多属于一个团队空间，二者互切即可，无需选择列表；
  切换中按钮与菜单锁定并在按钮旁常显「切换中…」，仍可主动关闭；成功后浮窗原位保留，更新空间信息和菜单，保留各空间会话位置与未发送输入；
  首次进入目标空间显示空白首页，再次进入恢复上次会话位置与输入。
- 状态保护：切换序号守卫（旧空间延迟响应不覆盖新空间视图）、切换中锁定重复操作、
  失败保留原空间与输入并提供重试；草稿按 `spaceId + conversationId` 隔离并持久化到 localStorage；
  损坏存储回退安全默认。
- 退出登录：二次确认；取消保持原状；确认仅结束本地演示登录状态（不宣称已注销真实服务会话，不删除数据）。

## 00–05 演示说明（本地模拟适配层）

**推荐演示输入**（完整案例，与 Figma 02/03 稿一致）：

```text
我们做便携咖啡机，想找美国户外类 Instagram 达人，这次先找 100 个，粉丝 1 万到 10 万，要有邮箱。
```

任意输入也可走通流程：模拟层按关键词提取目标市场（常见国家名）、产品（“我们做 X”）、品牌（“品牌是 X”）、达人方向（“找 X 达人”）与任务条件（人数/粉丝范围/邮箱）；提取不到的字段留空，确认画像时按必填校验就近提示（地区必填、每张画像的目标达人必填）。

**支持的对话修改表达**（未支持的表达会明确引导直接编辑画像，不声称已修改）：

- `目标市场改成 X`（同义前缀：目标国家/市场/地区；同义动词：改成/改为/换成/设为/修改为）
- `品牌改成 X`
- `目标达人改成 X`（作用于第 1 张目标达人画像）

同一字段按用户最后发出的意图处理：修改意图在点击发送瞬间认领序号，期间的手动表单编辑会阻止旧的模拟响应覆盖；回复只说明实际生效的字段。

**模拟范围与诚实边界**：不接真实 AI/上传/网页抓取；用户输入原样进入历史消息；附件与链接只做材料登记（“已接收”），内容不做真实解析、不标“材料提取”；品牌等演示建议值标「AI建议」，未核实内容在 02 卡明确说明；解析/创建结果均为本地模拟，成功消息注明演示流程到项目创建为止。

**测试注入口**（仅自动化测试使用，产品界面无调试开关）：`window.__creatorScoutSim.config` 可设
`sendFail / parseFail / createFail / modFail`（失败次数）与 `sendDelay / parseDelay / modDelay / createDelay`（毫秒），`window.__creatorScoutSim.reset()` 恢复默认。

## 设计还原口径

- 原始实现依据历史 Figma `vpKV1bb6IHNCkxSp2NPoqV` 节点数据（306:74 / 311:73 / 540:73 / 558:133 / 558:73 / 558:193 / 552:843 / 554:73 / 522:73），非画板名称或旧截图推测。
- UI文字（含团队名称及头像占位字）跟随首页 Noto Sans SC 字体栈；邮箱、数字沿用 Inter 数据字体栈。运行环境未安装这两种字体时按
  `Microsoft YaHei` / `Segoe UI` 等系统字体降级渲染——字体渲染效果取决于本机安装，原型未内嵌字体文件。
- 品牌 Discovery Mint / Primary Teal 仅用于品牌标识本身；后台交互仍用既有 Mint `#55D9B4` 语义。
- 当前已在1440×1024、1280×800检查主要内容、紧凑浮窗和主要操作不出屏；不代表本轮已对照最新Figma。小窗口只验证浮窗适配，不作为全站移动稿。

## 已知边界与原型假设

1. **空间切换交互已由用户确认**（2026-09-24）：点击切换按钮直接在个人空间与所属团队间互切，
   无选择列表；不增加丢弃确认，不默认丢弃未发送输入。（早前“两项选择列表”方案已废弃。）
2. 最近会话打开为只读历史 + 可编辑输入框，不重放消息；本轮不创建新会话、不接真实发送。
3. 「切换中」反馈为按钮旁提示芯片常显「切换中…」+ 浮窗功能按钮锁定，关闭入口仍可用；无骨架屏或页面级加载动画
   （默认模拟延时约 120ms，无人为长延时）。
4. localStorage 仅作本地演示持久化，不代表服务端存储。
5. 切换提示文案仍为「切换空间」；本次修正尺度与提示避让，不更改账户内部功能。主动点Instagram开启独立空白草稿，空间往返恢复最后活动草稿，旧草稿不清空。
